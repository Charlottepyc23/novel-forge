# 镜头语言规范（分镜标准化基准）

> 分镜表 `shot / camera / composition / light` 字段的取值基准，统一来自 `src/shot-language.ts`。
> 目的：让"景别 / 运镜 / 构图 / 光效"有标准词表，避免 LLM 自由发挥导致镜头语言漂移。

## 数据结构

`StoryboardShot` 的镜头语言字段已从自由字符串改为**受控枚举**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `shot` | `ShotSizeId` | 景别，单选 |
| `camera` | `CameraMoveId[]` | 运镜/机位，可多选（加号连接） |
| `composition` | `CompositionId?` | 构图，可选 |
| `light` | `LightingId[]` | 光效，可多选 |

## 词库（src/shot-language.ts）

### 景别 `shot`（单选）
| id | 中文 | 说明 |
|---|---|---|
| `extreme_wide` | 大远景 | 环境为主，人物很小 |
| `wide` | 远景 | 人在景中，交代环境 |
| `full` | 全景 | 全身，人物整体 |
| `medium` | 中景 | 膝部以上，叙事主力 |
| `medium_close` | 中近景 | 胸以上，表情+动作 |
| `close` | 近景 | 肩以上，突出表情 |
| `extreme_close` | 特写 | 脸/物细节 |
| `big_extreme_close` | 大特写 | 局部（眼/手/标志物） |

### 运镜 `camera`（可多选）
固定机位 / 推近 / 拉远 / 左摇 / 右摇 / 左横移 / 右横移 / 跟随 / 升镜 / 降镜 / 环绕 / 手持晃动 / 低机位仰拍 / 高机位俯拍 / 过肩镜头

### 构图 `composition`（可选）
三分法 / 中心对称 / 引导线 / 前景遮挡 / 低机位 / 俯拍 / 对称构图

### 光效 `light`（可多选）
顺光 / 侧光 / 逆光 / 顶光 / 伦勃朗光 / 霓虹光 / 硬光 / 柔光 / 氛围光 / 高反差

## 数据流

1. **LLM 生成**（`generateStoryboardTable`）：system prompt 已限定词表，LLM 输出标准中文 → 经 `normalizeShotSize / normalizeCameras / normalizeComposition / normalizeLightings` 归一化到枚举 id。
2. **存量数据**：旧自由文本分镜在读取时自动归一化到最近枚举（见 normalize 函数）。
3. **展示**：前端 `StoryboardTab` 用 `sizeZh / cameraZh / compoZh / lightZh` 转回中文展示。
4. **提示词输出**（`generateStoryboardPrompts`）：用 zh 版词块拼进镜头描述。

## 平台适配（后续）

`shot-language.ts` 每个词条已含 `en` 字段，便于适配英文平台（ComfyUI/SDXL）时输出英文镜头词。当前提示词走中文（即梦/豆包/可灵）。

## 约定

- **主题=颜色、密度=尺寸、镜头=词表**：新增镜头字段一律从词库取值，禁止自由文本。
- 新增词条：在 `shot-language.ts` 的 `SHOT_SIZES / CAMERA_MOVES / COMPOSITIONS / LIGHTINGS` 追加，并同步 normalize 函数。
